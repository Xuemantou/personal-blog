欢迎来到我的个人博客！

这是使用 Next.js + React 创建的第一篇文章。博客支持 Markdown 格式，并且集成了评论系统功能。

## 功能特点

- 基于 Next.js 15 构建
- 支持 Markdown 文章
- 集成评论系统（可配置 Giscus）
- 响应式设计
- TypeScript 支持

## 如何添加新文章

1. 在 `posts` 目录下创建新的 `.md` 文件
2. 在文件顶部添加 frontmatter：
   ```markdown
   ---
   title: "文章标题"
   date: "2026-04-15"
   ---
   ```
3. 使用 Markdown 编写文章内容
